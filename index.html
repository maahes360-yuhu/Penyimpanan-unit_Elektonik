Manajemen Penyimpanan Laptop

Kelola data posisi unit laptop di dalam rak secara efisien.

1. Impor Master Data Laptop (Excel)

Unggah file Excel (Kolom A: Nama Laptop, Kolom B: Serial Number) untuk auto-fill data.

2. Pilih Laptop yang Akan Disimpan:
Nama / Model Laptop Serial Number Keterangan Aksi
Hasil Pencarian Laptop
Serial Number Merek / Model Lokasi Rak Shelving Keterangan Status
Belum ada data tersimpan. Silakan simpan penempatan laptop terlebih dahulu.
